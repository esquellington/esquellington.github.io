* Problem

We want to solve a perfectly inelastic impact of a body B moving
towards a body A that is initially at rest, beside a static wall C (A
is sandwiched between B and C)

\[V_a^0 = 0 \quad V_b^0 > 0\]

\[m_a \leq m_b\]

\[
  w_a = \frac{\frac{1}{m_a}}{\frac{1}{m_a} + \frac{1}{m_b}}
  \quad
  w_b = \frac{\frac{1}{m_b}}{\frac{1}{m_a} + \frac{1}{m_b}}
\]
and \[w_b = 1-w_a\]

The mass ratio $\frac{m_b}{m_a}$ can also be written as $\frac{w_a}{1-w_a}$.

In a perfecly inelastic collisions, B will always move towards A, A
will always move towards C, C will never move.

The solution is $V_b(t+dt) = V_a(t+dt) = 0$ due to inelasticity and $V_a^0=V_c^0=0$.

* Inelastic collision response

Relative impact velocity
\[V_{ab}=V_b-V_a\]

Instantaneous velocity changes to conserve momentum
\[V_a^+ = V_a^- + V_{ab} w_a \]
\[V_b^+ = V_b^- - V_{ab} w_b \]

* SI Iteration $k$

Each iteration we'll:
- Solve collision AC $V_{ac}>=0$ resulting in $V_a^{(k)} = 0$
- Solve collision AB $V_{ab}<=0$, with $V_{ab} = V_b - V_a$ and $V_a = 0$ due to AC

So we have the recurrence:

\begin{align*}
V_b^{(k)} &= V_b^{(k-1)} - V_b^{(k-1)} w_b \\
          &= V_b^{(k-1)} w_a \\
          &= V_b^{(0)} w_a^{k}
\end{align*}

* Solution

Due to inelasticity, in the limit $V_b^{(\infty)} = 0$. In practice we'll
iterate until error drops below an absolute threshold $V_b^{(k^*)} <=
\epsilon$. We can assume $k^*$ is real and isolate it taking $\log$ on
both sides:

 \[ k^* = \frac{\log(\epsilon/V_b^0)}{\log(w_a)} \]

** Example

Setting $V_b^0 = 10m/s$ and $\epsilon = 10^{-3}$ we solve $k^* =
(\log(10^{-3}/10)) / \log(w_a)$

for mass ratios $m_b/m_a \in [1..20]$ and get $k^* \in [13, 190]$

* Conclusions

At first glance it looks like the error shrinks with $w_a < 1$ each
iteration, so the smaller $w_a$, the faster the error decreases, and
$w_a$ decreases with mass ratio $m_b/m_a$. Relative error reduces
steadily per-iteration.

However, converging below a given *absolute* precision $\epsilon$
requires incresingly more iterations as $w_a$ grows.

This means that for fast impacts and large mass ratios $m_b/m_a > 10$
we need a *lot* of iterations to converge below $\epsilon$. Overall
the iteration count grows *linearly* with the mass ratio (see last
plot)

This makes Sequential Impulses really inefficient for impact
problems. It's not so bad for persistent contact problems, where
impulses can be warmstarted and improved incrementally over multiple
timesteps, but that's not an option on the first impact timestep, as
no previous solution exists.
