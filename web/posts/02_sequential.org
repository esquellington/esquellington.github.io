...specifically, it sucks too little error per iteration, making it very
inefficient for rigid impact problems.

* Problem

We want to solve a perfectly inelastic impact of a rigid body B moving
towards a rigid body A that is initially resting beside a static wall
C. A is sandwiched between B and C.

(TODO sketch)

With velocity sign > 0 towards wall C, the initial conditions are:
\[ V_c = 0 ,\quad V_a(0) = 0 ,\quad V_b(0) > 0 \]

We'll assume $m_a \leq m_b$.

** Solution

Due to inelasticity A and B won't bounce, B will transfer momentum to
A, that will transfer it to C, that will absorb it all. Velocities
will never change sign. The logical solution is
\[V_a(t+\Delta t) = 0 ,\quad V_b(t+\Delta t) = 0\]

We'll see that solving this simple problem numerically with sequential
impulses needs a number of iterations that grows almost linearly with
the mass ratio $\frac{m_b}{m_a}$.

* Inelastic collision response

The instantaneous inelastic collision response for AB is
\[V_a^+ = V_a^- + V_{ab} w_a \]
\[V_b^+ = V_b^- - V_{ab} w_b \]
where $V_{ab}=V_b-V_a$ is the collision velocity and
\[
  w_a = \frac{\frac{1}{m_a}}{\frac{1}{m_a} + \frac{1}{m_b}}
  ,\quad
  w_b = \frac{\frac{1}{m_b}}{\frac{1}{m_a} + \frac{1}{m_b}} = 1-w_a
\]

* Sequential Impulses

Sequential impulses solves the problem iteratively as a sequence of
local collision responses between pairs of bodies. Each iteration
we'll solve collisions AC and AB

- Solve $V_{ac}^{(k)}>=0$, resulting in $V_a^{(k)} = 0$
- Solve $V_{ab}^{(k)}>=0$, with $V_{ab}^{(k)} = V_b^{(k)}$ because $V_a^{(k)} = 0$

So we have the recurrence:
\begin{align*}
V_b^{(k)} &= V_b^{(k-1)} - V_b^{(k-1)} w_b \\
          &= V_b^{(k-1)} w_a  \quad (\leftarrow w_a=1-w_b)\\
          &= V_b^{(0)} w_a^{k}
\end{align*}

The mass ratio $\xi = \frac{m_b}{m_a}$ can also be written as
$\frac{w_a}{1-w_a}$, and therefore the velocity changes on A,B do not
depend on their individual masses, only on their mass ratio, with $w_a
= \frac{\xi}{\xi+1}$ (derivation omitted).

** How many iterations do we need?
Due to inelasticity we know that in the limit $V_b^{(\infty)} = 0$. In
practice we'll iterate until error drops below an absolute threshold
$V_b^{(k^*)} < \epsilon$, represented by the horizontal line in the
previous plot.

We can assume $k^*$ is real and isolate it taking $\log$ on both sides
of $V_b^{(0)} w_a^{k} = \epsilon$ to obtain:


\[ k^* = \frac{\log(\epsilon/V_b^{(0)})}{\log(w_a)} = \frac{\log(\epsilon/V_b^{(0)})}{\log(\xi/(\xi+1))} \]

We plot $k^*(\xi)$ with the same parameters as above.

This looks surprisingly linear... and it *almost* is!

We can show that $\log(\xi/(\xi+1))$ is very close to $-1/(\xi+1)$ for
$\xi>2$ (see [[Linear Approx]]), so we can approximate $k^*(\xi)$ linearly
as
\[ k^* \approx -\log(\epsilon/V_b^{(0)}) (\xi+1)\]

and see that the slope $-\log(\epsilon/V_b^{(0)})$ changes very
moderately with both $V_b^{(0)}$ and $\epsilon$, and that the
parameter that affects $k^{*}$ the most is the mass ratio $\xi$.

* TODO Conclusions

Converging below a given *absolute* precision $\epsilon$ requires
proportionally more iterations as $\xi$ grows. Impact speed and
precision threshold do not matter much, compared to mass ratio, or
number of bodies.

This makes Sequential Impulses really inefficient for impact
problems. It's not so bad for persistent contact problems, where
impulses can be warmstarted and improved incrementally over multiple
timesteps, but that's not an option on the first impact timestep, as
no previous solution exists.

SI is very easy to implement, that's why it's so popular, but
(etc...). Can we do better somehow, without losing all simplicity?

** Impact N bodies with acceleration and Warmstarting

Warmstarting causes top body to bounce despite purely inelastic
collision, it get negative (upwards) vel on 1st iter. If we only save
WS from 2nd step, and apply it from 3rd step, convergence improves
greatly, steps >=3 req just 1 iter, BUT, for N=10 this causes UPWARDS
velocities (small, but negative), which means WS is overestimating
even if we only apply it on persistent contacts. MAYBE this would not
happen if we ignored separating contacts though

#+NAME: table-stack-ws
#+BEGIN_SRC C++ :includes <stdio.h> :results drawer
  int main( int argc, char** argv )
  {
      const int N(10);
      const float xi(1.0f), wa(xi/(xi+1));
      //const float ma(1), mb(1),
      const float eps(1e-3f);
      const int K(200);
      const bool bWarmstart(true);
      const float warmstart_decay01(0.99f);
      float V[N] = {}; V[N-1] = 10;
      float cached_Vab[N] = {};
      printf("t k");
      for( int n=0; n<N; n++ )
          printf(" V[%d]", n);
      int tk(0); //total iter across timesteps
      for( int t=0; t<10; t++ ) //2 frames
      {
          // Integrate t->t+dt
          const float dt(1.0f/60.0f), g(9.8f);
          for( int n=1; n<N; n++ )
              V[n] += dt*g;
          int k(0); //per-step iter

          // TODO Apply warmstarting, but only after contacts applied
          // their 2nd impulse, not 1st (persisted for >1 steps, save on
          // 2nd step, apply on 3rd)
          if( bWarmstart && t>1 )
          {
              for( int n=1; n<N; n++ )
              {
                  float wa_n( n==1 ? 0.0f : wa ); //B[0] is static
                  V[n-1] += cached_Vab[n] * wa_n;
                  V[n] -= cached_Vab[n] * (1-wa_n);
                  cached_Vab[n] *= warmstart_decay01;
              }
          }
          while( k < K && V[N-1] > eps )
          {
              if( k%10 == 0 )
              {
                  printf("\n%d %d",t,tk);
                  for( int n=0; n<N; n++ )
                      printf(" %2.4f",V[n]);
              }
              V[0] = 0.0f; //solve AC
              for( int n=1; n<N; n++ )
              {
                  float Vab(V[n]-V[n-1]); //solve AB
                  float wa_n( n==1 ? 0.0f : wa ); //B[0] is static
                  if( Vab < 0.0f ) //req separating contact (TODO not sure if correct, we should clamp total not per-iter)
                      Vab = 0.0f;

                  V[n-1] += Vab * wa_n;
                  V[n] -= Vab * (1-wa_n);

                  // Warmstarting (cached delta vel, should be lambda
                  // impulse but we don't save masses) --> save after
                  // 2nd step
                  if( bWarmstart && t>0 )
                      cached_Vab[n] += Vab;
              }
              k++;
              tk++;
          }
          printf("\n%d %d",t,tk);
          for( int n=0; n<N; n++ )
              printf(" %2.4f",V[n]);
      }
      return 0;
  }
