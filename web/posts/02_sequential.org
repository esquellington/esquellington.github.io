* Problem

We want to solve a perfectly inelastic impact of a body B moving
towards a body A that is initially at rest, beside a static wall C, so
that A is sandwiched between B and C.

(TODO sketch)

we'll see that solving this simple problem iteratively with sequential
impulses needs a number of iterations that grows with the mass ratio
$\frac{m_b}{m_a}$. We'll assume $m_a \leq m_b$.

* Inelastic collision response

The instantaneous inelastic collision response for AB is
\[V_a^+ = V_a^- + V_{ab} w_a \]
\[V_b^+ = V_b^- - V_{ab} w_b \]
where $V_{ab}=V_b^--V_a^-$ is the collision velocity and
\[
  w_a = \frac{\frac{1}{m_a}}{\frac{1}{m_a} + \frac{1}{m_b}}
  ,\quad
  w_b = \frac{\frac{1}{m_b}}{\frac{1}{m_a} + \frac{1}{m_b}} = 1-w_a
\]

In the perfecly inelastic case B will always move towards A, A will
always move towards C, and C will never move.

With the initial conditions
\[V_a^0 = 0 ,\quad V_b^0 > 0 ,\quad V_c = 0\]
The solution is
\[V_a(t+\Delta t) = V_b(t+\Delta t) = 0\]
Due to inelasticity A and B won't bounce, and all momentum will be
absorbed by the static object C.

* Sequential Impulses Iteration $k$

Each iteration we'll:
- Solve AC collision $V_{ac}>=0$ resulting in $V_a^{(k)} = 0$
- Solve AB collision $V_{ab}>=0$, where $V_{ab} = V_b - V_a$ and $V_a = 0$ (due to AC)

So we have the recurrence:

\begin{align*}
V_b^{(k)} &= V_b^{(k-1)} - V_b^{(k-1)} w_b \\
          &= V_b^{(k-1)} w_a \\
          &= V_b^{(0)} w_a^{k}
\end{align*}

The mass ratio $\xi = \frac{m_b}{m_a}$ can also be written as
$\frac{w_a}{1-w_a}$, and therefore the velocity changes on A,B do not
depend on their individual masses, only on their mass ratio, with $w_a
= 1/(\xi+1)$.

** How many iterations do we need?
Due to inelasticity we know that in the limit $V_b^{(\infty)} = 0$. In
practice we'll iterate until error drops below an absolute threshold
$V_b^{(k^*)} <= \epsilon$. We can assume $k^*$ is real and isolate it
taking $\log$ on both sides:

 \[ k^* = \frac{\log(\epsilon/V_b^0)}{\log(w_a)} \]

We can solve for the constants in the previous example and get $k^*
\in [13, 190]$ for $m_b \in [1..20]$

Next we plot $k^*(\xi)$ with mass ratio $\xi \in [1,100]$

* Conclusions

At first glance it looks like the error shrinks with $w_a < 1$ each
iteration, so the smaller $w_a$, the faster the error decreases, and
$w_a$ decreases with mass ratio $m_b/m_a$. Relative error reduces
steadily per-iteration.

However, converging below a given *absolute* precision $\epsilon$
requires incresingly more iterations as $w_a$ grows.

This means that for fast impacts and large mass ratios $m_b/m_a > 10$
we need a *lot* of iterations to converge below $\epsilon$. Overall
the iteration count grows *linearly* with the mass ratio (see last
plot)

This makes Sequential Impulses really inefficient for impact
problems. It's not so bad for persistent contact problems, where
impulses can be warmstarted and improved incrementally over multiple
timesteps, but that's not an option on the first impact timestep, as
no previous solution exists.
